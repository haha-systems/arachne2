# Compatibility decisions and experiments to preserve

**Task:** REF-04  
**Evidence:** [reference inventory](REFERENCE_INVENTORY.md), [frozen reference](REFERENCE_FREEZE.md), and the archived [Silk Stage 0 compatibility matrix](../silk2/reference/silk/stage0/COMPATIBILITY_MATRIX.md).

These decisions use four classes from the reimplementation plan. The archived Stage 0 matrix's `required`, `preferred`, `legacy`, and `abandoned` counts remain as recorded program-level labels; they are not renamed or inferred from this document. Host dependence is a separate dimension from compatibility priority.

## Gotchas

- Compatibility priority and host availability are independent. A required program can still need a host stub.
- A recorded timeout or missing host is evidence about that run's environment, not automatically a Silk language contract.
- Report reproduction results with their workload, inputs, provenance, and limitations. Do not generalize local synthetic outcomes.
